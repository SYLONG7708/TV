# 265 儲存庫資源比對與每日檢查

查核日期：2026-11-09，UTC+8。來源：[AA257265/265](https://github.com/AA257265/265)，初次比對版本 `366d9fbb11f37fbe120ec77bdb45dc2116f50cb7`。

## 本次結果

該儲存庫混合 TVBox 配置、直播清單及 Python／JS／JAR 適配器。這些檔案不是可直接加入網頁片庫的同一種 API；本次沒有執行上游程式。

依一般影視名稱清單篩選、移除純查詢參數及結尾斜線後，取得 **114 個 API 入口**，其中 **32 個已在現有設定**，其餘 **82 個為候選入口**。這是 API 網址數，不是缺少的影片數；不同來源可能收錄相同作品。

候選有 **44 個回應 CMS 目錄、38 個失敗**。82 個候選的判讀為：29 個既有網址變體、19 個抽樣疑似同片庫、32 個其他失敗入口，以及 2 個仍需確認的不同來源。網址變體與疑似同片庫分類可能包含回應失敗的入口，因此不能將所有欄位直接相加為「可用來源數」。分類中的既有判斷以本儲存庫 `sources/TVBOX` 與 `sources/All on-demand sources` 為準。

| 不同來源 | 本次檢查 | 適用限制 |
| --- | --- | --- |
| 憶夢影視 | 抽樣 8 筆明細，播放欄均為愛奇藝／優酷／騰訊網頁連結 | 抽樣沒有直接 HLS；不能把目錄成功當成 App 直接播放成功，未加解析器 |
| 全民視界 | 目錄可讀；最新一頁時間為 2026-06-21；2 部一般作品各抽 2 條 HLS，共 4 組清單及分段簽章檢查通過 | 技術上可作舊片備用候選；不適合作為每日追更的主要來源。未驗證全集、瀏覽器解碼或車機 |

本次沒有新增播放 API，沒有下載完整影片或修改 APK。新增的是來源每日比對排程；既有播放來源及更新排程保持原設定。

## 每日排程

- 工作流程：[Audit 265 upstream sources](https://github.com/SYLONG7708/TV/actions/workflows/audit-upstream-sources.yml)。
- 每日 **03:43，UTC+8** 檢查；GitHub 排程可能延遲，也可手動執行。
- 先釘選上游 commit，再讀取 7 份文字配置；若 commit 查詢暫時失敗，使用逐檔 SHA-256 記錄這次快照。
- 只比對已選的一般 HTTP CMS，探測少量目錄資料，以指紋識別疑似鏡像。
- 不執行遠端 Python、JS 或 JAR，不將新入口自動匯入片庫。
- 每次執行在 Actions 摘要及 artifact 保存 JSON／Markdown 報告，保留 90 天；不需本機開機。
- 全部上游配置失敗時工作流程報錯，不以空清單取代成功報告或播放資料。

本機重跑：

```powershell
node tools/audit-upstream-sources.mjs --timeoutMs 12000 --concurrency 8
node --test tests/upstream-source-audit.test.mjs
```

報告輸出為 `reports/upstream-265-latest.json` 與 `reports/upstream-265-latest.md`；工具只允許輸出至 `reports/`。

## 黃果短劇調查

已搜尋 GitHub 與公開網站。存在同名網站及非官方客戶端／爬蟲專案，部分標示成人內容；本次未接入這類來源，也未測試其取流或繞過機制。搜尋未找到能核實為官方、具有公開開發文件及長期服務依據的黃果內容 API，不能據此承諾長期可用。

此結論是本次搜尋與核實的範圍，不代表不存在任何私人或合作 API。搜尋結果頁標示「官方」或儲存庫公開，都不足以單獨證明 API 維護承諾或內容授權；該上游儲存庫的授權欄位亦未提供可辨識的授權條款。
